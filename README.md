## Objetivo

Apresentar os fundamentos do Aprendizado de Máquina e suas principais aplicações, combinando conceitos, materiais de aula e problemas reais para análise.

## Conteúdos

| Trilha | Tópicos |
| --- | --- |
| Fundamentos | Visão geral da área, introdução ao Aprendizado de Máquina e Python para dados |
| Aprendizado supervisionado | Classificação, regressão, MLP, SVM, árvores de decisão e Deep Learning |
| Aprendizado não supervisionado | K-Means e Mapas Auto-Organizáveis (SOM) |
| Modelos para texto | Processamento de Linguagem Natural (NLP) |
| Avaliação | Relatório e projeto final |

## Problemas norteadores

Os materiais usam problemas reais como ponto de partida, incluindo:

- Classificação e reconhecimento de dígitos escritos à mão
- Classificação de flores de íris
- Predição de compra de produtos
- Previsão de lucro de startups
- Segmentação de perfis de clientes
- Análise de perfis de estudantes
- Reconhecimento de faces
- Sistemas de perguntas e respostas

## Ferramenta de apoio

O curso usa **Python** como linguagem de apoio para análise e experimentação com dados. Uma referência inicial é a [Data Science Academy](https://www.datascienceacademy.com.br/).

## Projeto final

O projeto final consiste em escolher um problema relacionado à área de atuação ou interesse do estudante, encontrar uma base de dados e propor uma solução baseada em Aprendizado de Máquina. O [Kaggle](https://www.kaggle.com/datasets) é uma das fontes sugeridas de conjuntos de dados.
